# CodeBrew Quiz – Interactive JavaScript Quiz App

Assignment No. 3 – Build an Interactive JavaScript Quiz App (Week 7, Session 21)

## Features
- `questions` array with 8 objects (question, 4 options, answer)
- Question and option buttons rendered dynamically with DOM methods
- Green/red answer highlighting, correct answer revealed on a wrong pick
- Score tracking and a final score screen with feedback message
- "Next Question" button disabled until an option is chosen
- "Restart Quiz" resets index and score

## Run
Open `index.html` in any browser.
